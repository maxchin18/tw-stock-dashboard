# 台股即時主力分析儀表板 (tw-stock-dashboard)

輸入台股代碼（上市 / 上櫃 / ETF），即時抓取 **臺灣證券交易所 (TWSE)、櫃買中心 (TPEx)、FinMind** 的公開資料，
以 18 個面板呈現主力 / 法人 / 籌碼 / 技術 / 風險判讀，並在盤中透過 SSE **即時更新**。

- **零相依套件**：只需要 Node.js 20+，`npm start` 即可（不用 `npm install`）
- **淺色玻璃質感介面**（可一鍵切換深色），響應式版面
- **所有數字都能追溯**：每個指標都有固定公式（見下方「指標定義」），資料來源標示在畫面上；抓不到的資料顯示「—」，**不會用推估值取代**
- 內建 **單元測試** 與 **線上交叉驗證腳本**（TWSE ↔ FinMind、T86 ↔ FinMind、MI_MARGN ↔ FinMind、TPEx ↔ FinMind）

## 快速開始

```bash
git clone https://github.com/maxchin18/tw-stock-dashboard.git
cd tw-stock-dashboard
npm start
```

開啟 <http://localhost:3000>，輸入代碼（例：`2330`、`2360`、`0050`、`6488`）按「分析」。

環境變數（皆可省略）：

| 變數 | 說明 | 預設 |
|---|---|---|
| `PORT` | 伺服器埠號 | `3000` |
| `HOST` | 綁定位址 | `0.0.0.0` |
| `FINMIND_TOKEN` | FinMind API token（提高流量上限） | 無 |
| `HISTORY_MONTHS` | 抓取幾個月的歷史日K | `7`（約 140 個交易日） |
| `CACHE_DIR` | 磁碟快取目錄 | `.cache` |

## 即時更新怎麼運作

1. 前端呼叫 `/api/bundle?code=2330` 取得整包資料（日K、法人、融資券、當沖、即時報價、大盤指數）。
2. **分析引擎（`src/analysis/engine.js`）在瀏覽器與 Node 共用**，所有面板由同一份純函式計算。
3. 前端開啟 `/api/stream?code=2330`（SSE）。伺服器依盤勢階段輪詢 TWSE MIS 即時報價（盤中每 5 秒、盤前盤後 10 秒、收盤後 60 秒），有變動就推送。
4. 收到新報價時，前端把它合併成「今日進行中的K棒」重新計算全部面板，價格欄位會閃紅 / 閃綠。
5. 每 5 分鐘（收盤後 30 分鐘）重新抓一次整包，補上盤後才公布的官方日成交、法人、融資券資料。

盤中成交量顯示 MIS 的盤中累積量（不含盤後定價）；收盤後官方日成交資料公布時自動改用官方值。

## 資料來源與定義

| 資料 | 來源 | 備註 |
|---|---|---|
| 即時報價 | `mis.twse.com.tw/stock/api/getStockInfo.jsp` | 上市 / 上櫃皆可，含五檔、漲跌停、昨收 |
| 上市日K | `www.twse.com.tw/exchangeReport/STOCK_DAY`（個股日成交資訊） | 逐月抓取；**與 FinMind 逐日完全一致**（成交股數、金額、筆數） |
| 上櫃日K | FinMind `TaiwanStockPrice`（與 TPEx「每日收盤行情」相同定義） | 備援：TPEx `afterTrading/tradingStock`（該表僅一般交易時段成交張數，數值會略小） |
| 三大法人 | FinMind `TaiwanStockInstitutionalInvestorsBuySell` | 外資 = 外陸資 + 外資自營商；自營商 = 自行買賣 + 避險；**與 TWSE T86 逐項一致** |
| 融資融券 | FinMind `TaiwanStockMarginPurchaseShortSale` | 與 TWSE MI_MARGN 一致 |
| 當日沖銷 | FinMind `TaiwanStockDayTrading` | 沖銷比例 = 當沖成交量 / 當日成交量 |
| 證券索引 | TWSE `STOCK_DAY_ALL` + `t187ap03_L`、TPEx `tpex_mainboard_daily_close_quotes` + `mopsfin_t187ap03_O` | 含 ETF；每日更新一次 |
| 大盤指數 | MIS `tse_t00.tw` / `otc_o00.tw` | 加權指數、櫃買指數 |

單位：價格為元；成交量以「張」顯示（1 張 = 1,000 股，交易所原始為股，除以 1000 後保留小數，顯示時四捨五入）；法人買賣超以張顯示（原始為股）。

## 指標定義（全部為規則式計算，非機器學習）

| 指標 | 公式 |
|---|---|
| 趨勢評分 (0–5) | `close>MA5`、`MA5>MA10`、`MA10>MA20`、`MA20>MA60`、`close>MA60` 成立個數；5 強勢多頭 / 4 偏多 / 3 中性偏多 / 2 中性偏空 / 1 偏空 / 0 弱勢空頭 |
| 短線狀態 | 20 日區間位置 pos = (close − 20日低) / (20日高 − 20日低)：≥ 20 日高且量 ≥ 1.5 倍均量 → 強勢突破；≤ 20 日低 → 破底走弱；pos ≥ 0.7 高檔震盪；≤ 0.3 低檔整理；其他 區間震盪 |
| 主力行為 | r5 = 近 5 日三大法人買賣超 / 同期成交量：≥ +5% 積極布局；+1～+5% 小幅加碼；−1～+1% 觀望調節；−5～−1% 調節減碼；< −5% 大量出貨 |
| 籌碼結構 | r20 = 近 20 日法人買賣超 / 同期成交量：> +3% 集中；< −3% 分散；其他 中性 |
| 隔日沖風險 (%) | 0.3×爆量(今量/20日均量, 上限 3) + 0.25×漲幅(0～10%) + 0.2×振幅((高−低)/昨收, 0～10%) + 0.25×當沖比例(0～60%)，各項正規化為 0～1 後加權 |
| 籌碼健康度 (0–100) | 50 ± 20 日法人買賣超(15) ± 5 日法人買賣超(10) ± 融資 5 日減少(10) ± 收盤高於 20 日 VWAP(15) ± 量能在 0.5～2 倍均量(10) |
| 支撐 / 壓力 | S1/S2 = 20 日 / 60 日最低價；R1/R2 = 20 日 / 60 日最高價 |
| 風險等級 (1–5) | 年化波動(近 60 日對數報酬標準差 × √252)：<25% 1、<40% 2、<60% 3、<80% 4、其他 5；隔日沖風險 ≥ 60 再 +1 |
| 六維雷達 | 法人 = 50 + r20×5；動能 = (RSI14 + (50 + 10日漲幅×2.5)) / 2；趨勢 = 趨勢評分×20；籌碼 = 籌碼健康度；流動性 = 100×log10(20 日均成交金額 / 百萬) / 3.5；波動 = 100 − 年化波動；綜合 = 加權平均（前四項 0.2、後兩項 0.1）；A ≥ 80、B ≥ 65、C ≥ 50、D ≥ 35、E |
| 熱區圖 | 近 60 日，價格分 20 格，每日成交量依 [低, 高] 與各格的重疊比例分配；壓力區 = 現價 +2% 以上的量占比；價平區 = ±2%；支撐區 = −2% 以下；大量成交區 = 最大格 (POC) 占比；密集區 = 量 ≥ POC 50% 的格子合計占比 |
| 風險雷達 | 流動性風險 = 100 − 流動性；波動風險 = 年化波動；趨勢風險 = 100 − 趨勢；法人風險 = 50 − r5×5；籌碼風險 = 50 + 融資 5 日變化%×5 + (今量/均量 − 1)×20；主力風險指數 = 平均（<35 低、<50 中、<65 中高、其他 高） |
| 預測路徑 | 近 60 日對數報酬 μ、σ；第 h 日中位 = close·e^(μh)，±kσ 區間 = close·e^(μh ± kσ√h)；上漲機率 = P(10 日報酬 > +2%)、下跌機率 = P(< −2%)（常態假設）；主力方向機率 = P(10 日報酬 > 0)；強弱指標 = μ×252 |
| 成本結構 | 對每一天 t，取 t−19～t 的每日典型價 (高+低+收)/3 相對 close_t 的偏離：> +5% 深度套牢、+2～+5% 套牢、±2% 成本區、−5～−2% 獲利、< −5% 大幅獲利，以成交量加權占比 |
| 主力平均成本 | 20 日 VWAP = Σ成交金額 / Σ成交股數（盤中K棒的金額以典型價 × 股數估計） |
| 隔日沖五因子 | 主力賣出異常 = 今日法人賣出 / 20 日均賣出（上限 3）；量能換手率 = 今量 / 20 日均量（上限 3）；沖銷比例 = 當沖量 / 成交量；隔日回檔風險 = 隔日沖風險；日內波動率 = 振幅 / 10% |
| 多空能量 | 近 20 日紅K（收 > 開）成交量 vs 黑K 成交量 |
| 健康度五項 | 籌碼健康度；技術結構度 = (趨勢 + 動能) / 2；資金動能度 = 50 × (5 日均量 / 20 日均量)；波動風險度 = 年化波動；法人支撐度 = 法人維度 |
| 信號燈 | 紅：風險等級 ≥ 4 或趨勢評分 ≤ 1；綠：趨勢評分 ≥ 4 且風險等級 ≤ 2 且 r5 ≥ 0；其他 黃 |
| 市場情緒 | 散戶 = 50 + 融資 5 日變化%×5；法人 = 50 + r5×5；主力 = 50 + (收盤/VWAP20 − 1)%×5 + (5日均量/20日均量 − 1)×20；整體 = 平均（<40 悲觀、>60 樂觀） |
| 信心維度 | 模型準確度 = 近 60 個交易日中「趨勢評分 ≥ 3 → 看多」對「5 日後收盤是否上漲」的命中率（真實回測）；資料完整度 = 可用資料集 / 6 × min(1, 日K數 / 120)；訊號穩定度 = 1 − 近 20 日訊號翻轉次數 / 19；策略適用度 = 年化波動 20～45% 為 100，超出遞減 |
| 買賣力 | 大戶買盤 = 近 20 日法人買進股數 / 成交股數；散戶買盤 = 1 − 大戶買盤；散戶賣壓 = 1 − 法人賣出比例 |
| 多空強度 | 多方 = (趨勢 + 動能 + 法人) / 3；空方 = 100 − 多方；量能 = 資金動能度；信號等級由綜合評分：≥80 1 級、≥65 2 級、≥50 3 級、≥35 4 級、其他 5 級 |

## API

| 路徑 | 說明 |
|---|---|
| `GET /api/search?q=台積` | 代碼 / 名稱搜尋（含 ETF） |
| `GET /api/quote?code=2330` | 即時報價（MIS 正規化） |
| `GET /api/bundle?code=2330` | 日K + 法人 + 融資券 + 當沖 + 即時報價 + 指數 |
| `GET /api/analysis?code=2330` | bundle + 伺服器端計算的完整分析結果（與前端相同引擎） |
| `GET /api/market` | 加權 / 櫃買指數即時 |
| `GET /api/stream?code=2330` | SSE：`hello` / `quote` / `tick` / `indexes` 事件 |
| `GET /api/health` | 健康檢查 |

## 測試與驗證

```bash
npm test          # 單元測試：指標公式、解析器（以真實回應片段為樣本）、引擎（合成資料 + 2360 真實樣本）
npm run verify    # 線上交叉驗證（需網路）：TWSE ↔ FinMind、T86 ↔ FinMind、MI_MARGN ↔ FinMind、TPEx ↔ FinMind、MIS ↔ 官方日K
```

`npm run verify` 會逐日比對本月 TWSE 個股日成交與 FinMind 的開高低收 / 成交股數 / 金額 / 筆數，以及最新交易日三大法人（股）與融資券餘額（張），任何一項不一致即以非 0 結束。

